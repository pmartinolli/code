About this tool

This in-browser script retrieves from Wikidata the network around a starting tabletop role-playing game element and draws it on a timeline. It crawls backward (the works the element cites, follows, is based on, is inspired by or acknowledges) and onward (the works that cite, follow, are based on, are inspired by or acknowledge it). Click a work to build a new graph centred on it; Ctrl/⌘+click opens its Wikidata page. Drag to pan, scroll to zoom.

Line styles show the strength of the relation: plain for follows / followed by, dashed for cites work / acknowledged, dotted for based on / inspired by. Arrows point to the referenced work. A link drawn in red points to a work published later than the one referring to it; for citations this is usually a data issue: some TTRPGs list citations for all their editions combined, while others only include citations for specific editions. Contributions to improve this data on Wikidata are always welcome. Ideally, citations should be indexed at the edition level.

This tool is based on CitationTree by Nicolas Loizeau, and EntiTree by Orlando Groppo & Martin Schibel. The JavaScript code can be (quite) easily adapted to other needs.
